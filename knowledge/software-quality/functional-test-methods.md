# 功能测试用例设计方法论

> 基于黑盒测试经典方法。
> 推荐应用顺序：场景法 → 判定表 → 等价类+边界值 → 状态迁移 → 错误推测 → 正交法。
> 对每个功能点，按此顺序逐步展开，确保覆盖全面。

---

## 一、用例设计方法（按推荐顺序）

### 1. 场景法（流程覆盖）

**适用**：有明确业务流程的功能（注册、下单、审批等）

- **基本流**（Happy Path）：正常路径，所有步骤正常执行
- **备选流**：合法的分支路径（如：有优惠券 vs 无优惠券）
- **异常流**：错误处理路径（网络断开、权限不足、数据不存在）

**操作**：
1. 画出流程图（开始 → 结束）
2. 标出每个判断节点
3. 每条从头到尾的路径 = 一个场景 = 至少一条用例

### 2. 判定表 / 因果图（条件组合）

**适用**：多个条件共同影响结果的功能

- 列出所有**条件桩**（输入条件）
- 列出所有**动作桩**（输出结果）
- 穷举条件组合（2^N），标注每种组合的动作
- 合并等价组合，减少用例数

**示例**：登录功能
| 用户名正确 | 密码正确 | 账号未锁 | 结果 |
|:---:|:---:|:---:|:---|
| Y | Y | Y | 登录成功 |
| Y | Y | N | 提示账号已锁定 |
| Y | N | Y | 提示密码错误 |
| N | - | - | 提示用户不存在 |

### 3. 等价类划分（输入域分类）

**原则**：
- **有效等价类**：合法输入，可合并测试（一条用例覆盖多个有效类）
- **无效等价类**：非法输入，必须单独测试（每条用例只覆盖一个无效类）

**常见等价类划分**：
- 数字：负数 / 0 / 正整数 / 正小数 / 超大数
- 字符串：空串 / 单字符 / 正常长度 / 超长 / 纯数字 / 纯字母 / 混合 / 特殊字符 / emoji / SQL 关键词
- 日期：过去 / 今天 / 未来 / 闰年 / 2月29日 / 非法日期
- 文件：空文件 / 正常文件 / 超大文件 / 类型不匹配 / 损坏文件

### 4. 边界值分析（输入域边界）

**原则**：取 上点 / 离点 / 内点

对于范围 [min, max]：
- `min-1`（无效，刚越下界）
- `min`（有效，下界上点）
- `min+1`（有效，下界内点）
- `max-1`（有效，上界内点）
- `max`（有效，上界上点）
- `max+1`（无效，刚越上界）

**常见边界**：
- 字符串长度：0, 1, maxLen-1, maxLen, maxLen+1
- 数值：0, 1, -1, INT_MAX, INT_MIN
- 数组/列表：空, 1个元素, 满容量, 超容量
- 分页：page=0, page=1, page=最后一页, page=最后一页+1

### 5. 状态迁移法（有状态对象）

**适用**：订单状态、审批流、开关、有限状态机

- 列出所有**状态**
- 列出所有**事件/触发器**
- 画**状态迁移图**
- 覆盖所有**合法迁移路径**
- 测试所有**非法迁移**（如：已完成的订单再次支付 → 应拒绝）

### 6. 错误推测法（经验补漏）

**基于常见 bug 热点专门设计**：

- 空值：null, undefined, "", 0, false, [], {}
- 并发：多人同时编辑同一条数据、重复提交
- 时序：先执行步骤B再执行步骤A
- 网络：断网重连、请求超时、慢网络
- 特殊字符：`' " < > & / \ ; -- /* */`
- 大数据：超长文本、大量记录、大文件上传
- 重复操作：连续点击、重复调用接口

### 7. 正交试验法（降维组合）

**适用**：多参数 × 多取值，组合爆炸时

- 用正交表（如 L9(3^4)）选取代表性组合
- 保证任意两个参数的所有取值组合至少出现一次
- 大幅减少用例数（如 3参数×3取值 = 27 组合 → 9 条用例）

## 二、覆盖维度 Checklist

对每个功能点，逐维度自检"是否已覆盖"：

### 输入维度
- [ ] 必填/非必填、为空、为 null
- [ ] 类型：数字、字母、中文、特殊字符、emoji、空格、SQL/脚本特殊符号
- [ ] 长度：最小、最大、超长、单字符
- [ ] 格式：邮箱、手机号、身份证、日期、金额（小数位、负数）
- [ ] 取值范围：边界内、边界上、边界外
- [ ] 默认值、历史值回填

### 处理/逻辑维度
- [ ] 业务规则、计算公式、校验规则是否正确
- [ ] 条件分支（if/else、循环）是否全覆盖
- [ ] 多条件组合的优先级与互斥

### 输出维度
- [ ] 输出内容、格式、精度、单位是否正确
- [ ] 列表：空列表、单条、多条、分页、排序、筛选、最大数据量
- [ ] 提示信息（成功/失败/警告）是否正确

### 状态与数据维度
- [ ] 增、删、改、查闭环验证（增删改后查询是否一致）
- [ ] 删除/修改后的关联数据、级联影响、引用完整性
- [ ] 状态流转是否合法、状态与权限的联动

### 异常与边界维度
- [ ] 异常输入、异常时序（先B后A）、中途取消/退出
- [ ] 超时、网络中断、服务不可用时的表现
- [ ] 重复操作、重复提交、幂等性

### 并发与时序维度
- [ ] 多人同时操作同一数据（编辑冲突、库存超卖、并发扣款）
- [ ] 同一用户多端/多 Tab 操作

### 权限与角色维度
- [ ] 不同角色对该功能的可见性与可操作性
- [ ] 越权访问（直接访问 URL/接口）是否被拦截

### 兼容与环境维度
- [ ] 不同浏览器/设备/分辨率下功能可用
- [ ] 弱网/离线场景
